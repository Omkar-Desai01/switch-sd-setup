# Roadmap

Ideas, roughly in priority order. Open an issue before starting on a big one.

- [ ] Field testing on more cards and card readers (the main reason this is a 0.x release)
- [ ] Code-signed executables to avoid SmartScreen warnings
- [ ] Keep `compat.json` current automatically (read supported firmware from release notes)
- [ ] Check that the hekate release is recent enough for the installed Atmosphere
- [ ] Optional RCM payload injection from the PC (today the checklist tells you what to do)
- [ ] Localisation of the desktop app
- [ ] More components in `manifest.json` (community-requested homebrew)

Out of scope, and pull requests for these will be closed: signature or ticket-check patches, downloading games,
distributing keys or firmware, and anything else whose purpose is to run software you do not own.
